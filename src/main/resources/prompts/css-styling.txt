═══════════════════════════════════════════════════════════════
FRONTEND STYLING RULES — SaaS Premium (Vercel-inspired)
═══════════════════════════════════════════════════════════════

⛔ EXTERNAL FRAMEWORKS BANNED: Do NOT import Pico.css, Tailwind, DaisyUI, Bootstrap, 
   Material UI, UnoCSS, or any CSS framework via CDN <link> or <script>. ALL styling 
   must use the custom properties defined below. A single <link> to an external 
   stylesheet is a CRITICAL violation. Write all CSS from scratch.

CSS & VISUAL DESIGN: Create a clean, sophisticated dark-mode stylesheet. Use a 
"SaaS Premium" aesthetic: high-contrast typography, generous whitespace, and 
subtle depth. The result must feel professional, modern, and polished. 
NEVER leave browser defaults.

═══════════════════════════════════════════════════════════════
THEME & COLOR SYSTEM
═══════════════════════════════════════════════════════════════

Default DARK THEME. Define ALL colors as CSS custom properties in :root.

Surface system — Zinc/Slate gray scale on pure black:
  --bg-app:       #000000 (pure black — page background)
  --bg-surface:   #09090b (cards, panels, sidebars)
  --bg-elevated:  #18181b (dropdowns, popovers, modals, hover states)
  --bg-hover:     #27272a (interactive hover)
  --bg-active:    #3f3f46 (active/pressed states)

Text hierarchy:
  --text-primary:   #fafafa (high-contrast body/heading text)
  --text-secondary: #a1a1aa (descriptions, metadata, timestamps)
  --text-muted:     #71717a (placeholders, disabled, tertiary info)
  --text-disabled:  #3f3f46 (disabled interactive text)

Color — MEANING ONLY, never decoration:
  --accent-blue:   #0070f3 (success, active, primary links, focus rings)
  --accent-amber:  #f5a623 (warning, in-progress)
  --accent-red:    #ef4444 (error, destructive)
  --accent-gray:   #71717a (inactive, queued, neutral)

Borders & Shadows:
  --border-default: #27272a (1px solid — default for all borders)
  --border-hover:   #3f3f46 (on hover/focus)
  --shadow-sm:      0 1px 2px rgba(0,0,0,0.4);
  --shadow-md:      0 4px 6px -1px rgba(0,0,0,0.5), 0 2px 4px -1px rgba(0,0,0,0.4);

═══════════════════════════════════════════════════════════════
TYPOGRAPHY
═══════════════════════════════════════════════════════════

Use a clean system sans-serif stack:
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif;
  Monospace: 'JetBrains Mono', 'SFMono-Regular', 'Menlo', monospace;

Rules:
  - Base: 15px (default), line-height 1.6 for body.
  - Headings: 18-24px, font-weight 700 (Bold), line-height 1.25.
  - Headings: letter-spacing -0.02em (tightening for modern feel).
  - Secondary text: 13px, color var(--text-secondary).
  - Muted captions: 11px, color var(--text-muted), uppercase optional for labels.
  - Monospace for code blocks, IDs, timestamps, technical data.

═══════════════════════════════════════════════════════════════
LAYOUT & SPACING
═══════════════════════════════════════════════════════════

- 8px spatial grid: all padding, margins, gaps should be multiples of 8 (8, 16, 24, 32, 48, 64px). 
  Use 4px ONLY for tight internal component spacing.
- Generous whitespace between sections — the design MUST breathe.
- CSS Grid for page structure. Flexbox for component internals.
- Max-width 1200px centered for content. Full-width for navigation.
- Responsive via @media — mobile-first.
- box-sizing: border-box on *.

═══════════════════════════════════════════════════════════════
COMPONENTS
═══════════════════════════════════════════════════════════

Cards / Panels:
  - background: var(--bg-surface) (#09090b)
  - border: 1px solid var(--border-default) (#27272a)
  - border-radius: 8px (Modern rounded feel)
  - box-shadow: var(--shadow-sm)
  - On hover: background var(--bg-elevated), shadow var(--shadow-md).

Buttons (Primary CTA):
  - background: #ffffff (white-on-black)
  - color: #000000
  - font-weight: 600
  - border-radius: 6px
  - padding: 10px 20px
  - Hover: background #e4e4e7, transform: translateY(-1px);
  - Active: transform: translateY(0);

Buttons (Ghost / Secondary):
  - background: transparent
  - border: 1px solid var(--border-default)
  - color: var(--text-primary)
  - Hover: background var(--bg-elevated)

Inputs:
  - background: #000000
  - border: 1px solid var(--border-default)
  - border-radius: 6px
  - padding: 10px 14px
  - color: var(--text-primary), placeholder: var(--text-muted)
  - Focus: border-color #fafafa, outline: none;

Modals / Overlays:
  - background: rgba(9, 9, 11, 0.8)
  - backdrop-filter: blur(8px) (Glassmorphism effect)
  - border: 1px solid var(--border-default)
  - border-radius: 12px

═══════════════════════════════════════════════════════════════
MOTION & GLOBAL POLISH
═══════════════════════════════════════════════════════════

- Base: transition: all 200ms cubic-bezier(0.4, 0, 0.2, 1);
- Hover: subtle translateY(-1px) and shadow increase for interactive items.
- Scrolling: scroll-behavior: smooth on html.
- Scrollbar: 8px, track transparent, thumb #3f3f46, thumb:hover #52525b.
- Selection: ::selection { background: rgba(0, 112, 243, 0.3) }.
- Font-smoothing: -webkit-font-smoothing: antialiased.

═══════════════════════════════════════════════════════════════
HARD BANS (DO NOT USE)
═══════════════════════════════════════════════════════════

⛔ Purple / violet / indigo accent colors (unless requested).
⛔ Heavy bevels, inner glows, or glossy 2000s-style gradients.
⛔ Radius > 12px or radius 0px unless for full-bleed sections.
⛔ Decorative color — use color only to guide attention or show status.
⛔ Generic shadows (blue/red shadows are banned).
⛔ Random spacing values that break the 8px grid.

Minimalism is key, but it must be refined minimalism. Use subtle depth 
(shadows and glassmorphism) to differentiate layers.
