═══════════════════════════════════════════════════════════════
FRONTEND STYLING RULES — Vercel/Geist Design System
═══════════════════════════════════════════════════════════════

CSS & VISUAL DESIGN: Create a clean, restrained dark-mode stylesheet inspired by Vercel's
Geist design system. The result must feel like Vercel's dashboard — pure black, almost
monochrome, with color used ONLY to communicate meaning. NEVER leave browser defaults.

═══════════════════════════════════════════════════════════════
THEME & COLOR SYSTEM
═══════════════════════════════════════════════════════════════

Default DARK THEME. Define ALL colors as CSS custom properties in :root.

Surface system — 10-step gray scale on pure black:
  --bg-app:       #000000 (pure black — page background, NEVER dark gray)
  --bg-surface:   #111111 (cards, panels, sidebars)
  --bg-elevated:  #1a1a1a (dropdowns, popovers, modals, hover states)
  --bg-hover:     #252525 (interactive hover)
  --bg-active:    #333333 (active/pressed states)

Text hierarchy:
  --text-primary:   #ededed (high-contrast body/heading text)
  --text-secondary: #a1a1a1 (descriptions, metadata, timestamps)
  --text-muted:     #666666 (placeholders, disabled, tertiary info)
  --text-disabled:  #333333 (disabled interactive text)

Color — MEANING ONLY, never decoration:
  --accent-blue:   #0070F3 (success, active, primary links, focus rings)
  --accent-amber:  #f5a623 (warning, in-progress)
  --accent-red:    #e5484d (error, destructive)
  --accent-gray:   #666666 (inactive, queued, neutral)

  ⛔ Do NOT use color for decoration — no gradient backgrounds, no colored card
  borders, no tinted surfaces. The UI is monochrome with strategic color accents.
  ⛔ Do NOT use violet, purple, or indigo as accent colors.

Borders:
  --border-default: #252525 (1px solid — default for all borders)
  --border-hover:   #333333 (on hover/focus)
  No colored borders except as thin left-edge status indicators (3px).

═══════════════════════════════════════════════════════════════
TYPOGRAPHY
═══════════════════════════════════════════════════════════════

Use a clean system sans-serif stack:
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif;
  Monospace: 'SFMono-Regular', 'Consolas', 'Liberation Mono', 'Menlo', monospace;

Rules:
  - Base: 13-14px, line-height 1.5 for body.
  - Headings: 16-20px, font-weight 600 (semibold, NOT bold), line-height 1.2.
  - Headings: letter-spacing -0.01em (subtle tightening).
  - Secondary text: 12px, color var(--text-secondary).
  - Muted captions: 11px, color var(--text-muted), uppercase optional for labels.
  - Monospace for code blocks, IDs, timestamps, technical data.

═══════════════════════════════════════════════════════════════
LAYOUT & SPACING
═══════════════════════════════════════════════════════════════

- 4px spatial grid: all padding, margins, gaps should be multiples of 4
  (4, 8, 12, 16, 24, 32, 48, 64px).
- Generous whitespace between sections — the design breathes.
- CSS Grid for page structure. Flexbox for component internals.
- Max-width 1200px centered for content. Full-width for navigation.
- Responsive via @media — mobile-first.
- box-sizing: border-box on *.

═══════════════════════════════════════════════════════════════
COMPONENTS
═══════════════════════════════════════════════════════════════

Cards / Panels:
  - background: var(--bg-surface) (#111)
  - border: 1px solid var(--border-default) (#252525)
  - border-radius: 4px (NOT 12px, NOT rounded-lg)
  - NO box-shadow. Cards are flat, separated by border only.
  - On hover: background var(--bg-elevated) OR border var(--border-hover)
  - Active/selected: left border 2px solid #ededed

Buttons (Primary CTA — use sparingly, one per view):
  - background: #ededed (white-on-black)
  - color: #000000
  - font-weight: 500
  - border-radius: 4px
  - padding: 8px 16px
  - Hover: background #ccc

Buttons (Ghost / Secondary — default for most buttons):
  - background: transparent
  - border: 1px solid var(--border-default)
  - color: var(--text-primary)
  - Hover: background var(--bg-elevated)
  ⛔ NEVER use colored button backgrounds (no green "success", no red "delete").
  Use ghost + colored text for destructive actions.

Buttons (Link-style):
  - No border, no background
  - color: var(--accent-blue)
  - text-decoration: none; hover: underline

Inputs:
  - background: var(--bg-surface) (#111)
  - border: 1px solid var(--border-default) (#252525)
  - border-radius: 4px
  - padding: 8px 12px
  - color: var(--text-primary), placeholder: var(--text-muted)
  - Focus: border-color var(--border-hover) (#333)
  ⛔ NO box-shadow, NO outline glow, NO ring on focus. Just a border color change.

Tags / Badges / Status:
  - border-radius: 2px (NOT pill-shaped)
  - Small text (11-12px)
  - Muted background: var(--bg-elevated)
  - Status dots: 6px solid circles inline before text

Tables:
  - No zebra striping
  - Row border-bottom: 1px solid var(--border-default)
  - Header: var(--text-muted), uppercase, 11px, letter-spacing 0.05em
  - Cell padding: 12px 16px

Navigation:
  - bg #000, bottom/right border var(--border-default)
  - Active item: bg var(--bg-elevated), text var(--text-primary)
  - Inactive: text var(--text-muted)
  - No colored active indicators — white text is enough

Border-radius rules (STRICT):
  - 2px for badges, chips, tags
  - 4px for cards, inputs, buttons, modals
  - 6px maximum for large dialogs
  ⛔ NEVER use rounded-full, rounded-xl, rounded-2xl, or radius > 6px on containers

═══════════════════════════════════════════════════════════════
MOTION & TRANSITIONS
═══════════════════════════════════════════════════════════════

- Base: transition: 150ms ease-out for hover bg/border changes.
- New content: opacity 0→1 over 150ms.
- ⛔ NO bounce, NO scale transforms, NO glow effects, NO pulse animations.
- ⛔ NO staggered slide-up page-load animations.
- Loading spinners: simple rotating ring (border animation), gray color.

═══════════════════════════════════════════════════════════════
GLOBAL POLISH
═══════════════════════════════════════════════════════════════

- Font rendering: -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
- Scrollbar: thin (6px), track transparent, thumb #333, thumb:hover #555
- Selection: ::selection { background: rgba(0, 112, 243, 0.3) }
- Focus-visible: outline: 2px solid var(--accent-blue); outline-offset: 2px
- Smooth scrolling: scroll-behavior: smooth on html

═══════════════════════════════════════════════════════════════
WHAT TO AVOID (HARD BANS)
═══════════════════════════════════════════════════════════════

⛔ Purple / violet / indigo accent colors
⛔ Gradient backgrounds or colored surfaces
⛔ Border-radius > 6px on any container
⛔ Box shadows on cards (flat borders only)
⛔ Colored button backgrounds (green success, red delete, blue submit)
⛔ Glow effects, pulse animations, bounce transitions
⛔ Dark gray (#1a1a1a or similar) as page background — MUST be pure #000
⛔ Decorative color usage — color is for meaning only
⛔ Components that look like Bootstrap, Material UI, or Tailwind defaults
⛔ Random spacing values that break the 4px grid

The UI must feel like Vercel's dashboard — clean, restrained, almost monochrome,
with surgical use of color to communicate status and guide attention.
