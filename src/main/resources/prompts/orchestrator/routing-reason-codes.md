# Routing Reason Codes

Use short snake_case reason codes. Prefer these when they fit:

- `general_chat`
- `read_only_explanation_request`
- `read_only_search_or_file_request`
- `plan_or_how_would_request`
- `review_request`
- `missing_scope_or_target`
- `run_lifecycle_request`
- `local_git_or_shell_request`
- `explicit_code_mutation_request`
- `implementation_needs_confirmation`
- `security_or_destructive_request`

The reason code must explain the selected route, not merely repeat it.
