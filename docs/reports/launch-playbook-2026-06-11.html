02The story

“AI that ships pull requests your team actually merges.”

The frame: between copilots (you drive every keystroke) and full-autonomy agents (black box, surprise bills) sits delegation with a contract — approve the scope and the price up front, get back a PR with a receipt.

1 · Plan gateApprove the plan and the price before a token is spent. Credits charge at approval, refund on failure.
2 · Verified scoreDeterministic 0–100: code 30 · build 25 · your tests 20 · reviewer 20 · criticals 5. Never self-rating. This is the brand.
3 · Your repos, your keysReal PRs from your GitHub identity. BYOK with zero per-run markup.

Say: verified score · plan gate · spec · run · receipt · merge-able PR.
Don’t say: SOC 2 (until certified) · trial (none exists) · Solo (retired — it’s Pro) · ExecuteSpec-bot (PRs use the caller’s PAT) · IDE jargon in marketing.

Lead: spec → plan gate → verified PR · the score · BYOK.  Support: readymade library · autofix · project workbench.  Hide/beta: benchmark dashboards · TB/SWE adapters · CLI + VS Code (“beta”) · pause/resume · standards/contracts/ADRs (sell as Enterprise governance, don’t demo).
