# CODEMAP

Mechanical index of every top-level package, REST controller, agent, tool, JPA entity, Flyway migration, LLM prompt, frontend page, frontend component, and feature flag in this repository.

Base Java package: `com.navneet.executespec` (all paths under `src/main/java/com/navneet/executespec/`).

Migration head: **V251** in the current worktree (V240 adds the CLI/VS Code agent-session protocol tables; V241 seeds the CLI local-hands feature flag; V242 adds the account-level provider preference used by web, CLI, and VS Code; V243 adds durable per-call LLM usage in `run_step_usage`; V244 defaults local-hands execution on for CLI/VS Code local mode; V245 adds the managed-AI usage ledger; V246 adds durable run scoping to agent sessions; V247 adds first-class action-event correlation ids; V248 force-corrects FREE run-limit rows back to 5 when stale rows still carry an unlimited sentinel; V249 seeds default-off executor goal-decision enforcement; V250 persists task goal/continuation decision JSON; V251 persists final run-level goal proof JSON). Frontend chrome: the **Console** control plane (`frontend/src/console/`) is the only protected web shell since 2026-06-12; `frontend/src/ide/` remains the route-level protected surface layer, and `frontend/src/signal/` holds only public + admin pages + shared components.
