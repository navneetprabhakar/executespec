# ExecuteSpec One-Page Writeup

ExecuteSpec is a spec-driven AI software foundry. Today, its core product turns a plain-English software requirement into a reviewable pull request. The user writes the spec, reviews a generated task plan and cost estimate, approves the plan gate, and then the system executes the work through controlled coding tools. The result is not just a diff. It is a PR with build/test/reviewer evidence and a verified score that explains how much trust the system can defensibly attach to the change.

The product is built for the gap between IDE copilots and fully opaque autonomous agents. Copilots help engineers type faster, but the engineer still has to orchestrate the work, remember context, run tests, and decide whether the output is safe. Fully autonomous agents can hide too much: what plan was followed, what cost was incurred, and what evidence supports the final claim. ExecuteSpec sits in the middle: async delegation with a human plan gate and a transparent verification trail.

The core workflow is simple. A developer submits a spec against a project or repo. ExecuteSpec classifies the work, creates a task plan, estimates cost, and waits. After approval, worker agents modify the workspace through schema-bound tools, reviewer agents inspect the result, build/test checks run where available, and the platform opens or updates a PR. For teams, the project workbench adds repo linking, architecture docs, project memory, uploaded-document RAG, tech-debt tracking, code review, PR review, and cross-repo context. The terminal CLI is released and working, extending the same server brain into a developer-local workflow.

The broader roadmap is to make this one control plane cover the software lifecycle. The first expansion is a DevOps, deployment, and governance agent for Terraform, Docker, release workflows, policy checks, environment drift, and controlled terminal/web operations. The second is Virtual SRE: an AI observability agent that monitors logs, metrics, traces, alerts, and service health, raises evidence-backed issues, and routes remediation into ExecuteSpec PRs for review. The third is a Data Pipeline Builder for SQL, NoSQL, warehouses, lakehouses, HDFS, Apache Iceberg, Databricks, Snowflake, and unstructured sources, with ExecuteSpec owning compute/orchestration while customers own source and destination storage by default. A managed destination can be offered separately, and an analysis layer can let users slice, dice, visualize, and inspect processed data.

The business model reflects the economics of LLM software delivery. Free gives users enough room to evaluate the product: 15 monthly small-spec runs with a $3 per-run cap. Pro is $29/month or $289/year for 30 managed-key runs with a $5 per-run cap. Team is $39/seat/month, from one seat, and uses BYOK so customers run against their own Anthropic, OpenAI, Gemini, DeepSeek, OpenRouter, or Fireworks lanes where configured. Enterprise is custom, with org-level model controls, DPA/SLA path, and expanded admin/security review.

The important claim is not "AI replaces engineers." The credible claim is narrower and stronger: ExecuteSpec helps teams delegate bounded implementation work while preserving the controls needed to review and merge responsibly: plan approval, cost visibility, tool traces, validation evidence, and PR output.

Current proof still has limits. Payment flows, benchmark publication, enterprise compliance claims, and the three expansion product lines need live evidence before stronger external language. That discipline is intentional. The product category will be won by trust, not by bigger autonomy claims.
