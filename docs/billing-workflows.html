10. Edge Cases

PAST_DUE + Upgrade

User with PAST_DUE subscription can still upgrade to higher tier. Old sub cancelled immediately, new sub created. Prevents user from being stuck in limbo.

Founder Pricing + Upgrade

If target plan has founderPricing=true, slot availability is checked first. If no slots, upgrade is blocked. Founder pricing locks in forever once activated.

Webhook Before Frontend Verify

Razorpay may fire subscription.charged before user clicks "Complete" in browser. Webhook activates sub + generates invoice. Frontend verify becomes a no-op (sub already ACTIVE, invoice deduped).

Org User Billing

If user belongs to an org, BillingEntityResolver returns org as billing entity. Subscription is org-level. Tier applies to entire org. Only ORG_ADMIN can manage billing.

SUPER_ADMIN Tier

SUPER_ADMIN global role auto-resolves to ENTERPRISE tier. No subscription needed. Unlimited runs, full access. Handled by TierEnforcementService.resolveUserTier().
