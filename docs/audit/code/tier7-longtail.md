Status: **DONE** · Updated 2026-05-29 · 14 packages / ~95 files / ~6,800 lines · all read in full

## What it is
The growth + ops + enterprise-readiness long tail: activity feed, governance cost-guards, GDPR/retention + disk/SCM cleanup crons, project export, activation analytics, the pre-reviewer lint pass, the (retired) rollout canary, the OpenAPI test-suite agent, the anonymous-trial funnel, onboarding sandboxes, the referral loop, public landing/exec-snapshot endpoints, the contact form, and the readymade/migration slot machinery.

## Findings — uniformly clean + incident-hardened. One real exposure, the rest minor.

### 🟡 `rollout/` — a retired parallel orchestrator still wired to an authenticated-but-UNMETERED endpoint
`rollout/RunService` is a **second, in-memory V2 pipeline** (planner→executor→reviewer) with "Phase 9 baseline — no DB persistence, no cost/credit tracking, no SSE." Its `RolloutRunController` exposes **`POST /api/v2/runs`** + `GET /api/v2/runs/{id}` with **no `@PreAuthorize`, no access guard, no tier/quota/credit/cost-cap check, no ownership stamping**. SecurityConfig routes it through the `/api/**` → `.authenticated()` catch-all (the canary `permitAll` was already removed), so it's **not** an open-internet burn — but **any authenticated user (incl. FREE) can run the full real LLM pipeline unmetered**, bypassing the entire credit/quota/cost-cap system that `/api/runs` enforces (incl. the `GovernanceGuard` cost-approval + project-spend-cap that `RunController.approve` now applies). The run isn't DB-persisted and its cost lands on a phantom `v2-<uuid>` bucket, invisible to per-run accounting. Its own comment says "V2 is the only harness and is accessed via the regular `/api/runs` surface" — i.e. this package is **superseded/dead**. **Fix:** delete `rollout/` (4 files, 589 LOC) or gate `/api/v2/runs` to SUPER_ADMIN like the `/api/v2/test/**` controllers were (RL-2026-05-027). Same class as that finding; this one slipped because it's not under `/test/`.

### 🟢 The cost-governance + lifecycle infra is genuinely strong
- 🟢 **`governance/GovernanceGuard` is wired + correct** — `RunController.approve` calls `assertCanApproveCost` (org `require_admin_approval_above_usd` → 403 escalation) + `assertProjectSpendCap` (project monthly cap via the **DB-aggregate** `sumActualCostByProjectAndSince`, not a heap scan → 402); `ProjectRepoService` calls `assertRepoOwnerAllowed` (org GitHub-owner allowlist). All no-op when caps NULL, SUPER_ADMIN-bypass. This is the *good* cost-control surface — the rollout endpoint's sin is sidestepping exactly these.
- 🟢 **`compliance/` is incident-hardened** — `DataRetentionService` (per-tier retention via bounded `tier_config` iteration, soft→7d-grace→hard delete, tombstone+archived purges with per-row try/catch), `WorkspaceDiskCleanupJob` (3-category classify, never touches active runs, runId-shape heuristic, ShedLock, sequenced after the row sweep — born from "137 orphaned dirs" incident), `StaleScmCleanupJob` (closes dead PRs + deletes stale `executespec/*` branches with the run-owner's PAT). All ShedLock'd off-hours crons.
- 🟢 **`lint/LintPass`** is a cost-saver done right — deterministic formatters (prettier/spotless/black/gofmt/rustfmt) run between executor and reviewer so the reviewer doesn't re-type files at 5–15K tokens; **strips secret-bearing env vars** before each formatter (same discipline as deployment's ComposeExecutor), `ProcessBuilder(argv)`, per-tool + total timeouts, bounded mtime walk. Flag-gated default-on.
- 🟢 **`activity/`** — tenant-guarded feed (mandatory time-window for partition pruning, DB-LIMIT variant to avoid heap-loading, tier-filtered), async dual-write chokepoint (`ActivityEventEmitter` → feed + legacy audit, never throws), partition pre-create/retention jobs with a **regex rail against SQL-injection-via-locale-drift** in the DDL concat, dry-run-default retention. `@EqualsAndHashCode(of=PK)` fix on the composite-key entity.
- 🟢 **`export/ProjectExportController`** — defense-in-depth: `@PreAuthorize` ORG_ADMIN+ **AND** `assertCanRead(projectId)` (explicit "admin SOMEWHERE ≠ admin THIS project" note); bundle carries no secrets.
- 🟢 **`anonrun/`** — layered anti-abuse for the unauthenticated trial: spec cap → Redis per-IP rate limit (3/hr, fail-open by design w/ cost-cap as 2nd line) → cheap `AbuseHeuristic` (prompt-injection markers + banned topics, zero-LLM-cost pre-filter) → 24h session; real dispatch is interface+stub only (flag-gated OFF, real impl deferred pending a $0.01 cost-cap design).
- 🟢 **`analytics/`** (idempotent activation funnel, async, PostHog no-op when unconfigured, SUPER_ADMIN read), **`onboarding/`** (idempotent sandbox provisioning + hourly archive-not-delete GC), **`referral/`** (grant on referee's first READY run not signup = anti-fraud, `granted_at` idempotency anchor), **`landing/`** (public anonymized marketing reads, markdown-stripped to stop a past raw-markdown leak), **`contact/`** (Jira-or-email feedback, validated DTO), **`composer/SlotValidator`** (FILE_PATH traversal guard, unknown-key rejection) — all clean.
