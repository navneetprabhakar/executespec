## Chrome + routing (IDE default, Console opt-in)

The default chrome is the VS Code-style **IDE workspace** (`ide/IdeWorkspace`). `App.tsx` renders the same protected route tree inside `ConsoleShell` only when `localStorage.getItem('es:console') === '1'`; otherwise it mounts `IdeWorkspace`. The old Signal↔IDE A/B toggle + the `ui.ide.default` flag path were removed. The routing model:

- **Public routes** (`/login`, `/register`, `/verify`, `/forgot-password`, `/reset-password`, `/accept-invite`, `/auth/callback`, `/welcome`, `/pricing`, `/trust`, `/terms`, `/privacy`, `/dpa`, `/shared/:token`) render **standalone Signal pages** with no chrome — there is no IDE-native auth/marketing surface yet.
- **Protected routes** mount inside `<IdeWorkspace>` by default or `<ConsoleShell>` when opted in, and render IDE-native surfaces: `/home`→IdeWelcome or ConsoleHome, `/compose`→IdeCompose, `/plan/:id`→IdePlan, `/live/:id`→IdeLive, `/result/:id`→IdeRunResult, `/runs`→IdeRuns, `/projects`→IdeProjects, `/projects/:id/*`→IdeProjectTabs/IdeProjectMore, `/account`→IdeAccount, `/billing`→IdeBilling, `/plans`→IdePlans, `/api-keys`→IdeApiKeys, `/org-members`→IdeOrgMembers, `/org/settings`→IdeOrgSettings, `/integrations`→IdeIntegrations, `/admin`→IdeAdmin, `/deployments`→IdeDeployments, plus the discovery/system surfaces (`ide/IdeDiscovery.tsx` + `ide/IdeSystem.tsx`).
- **The only Signal page reachable from the protected tree** is `MiscPages`' `AdminPage` at `/admin/*` (deep links with no IDE surface). Bare no-id `/live` + `/result` redirect to `/runs`. The **2026-05-23 cleanup** deleted the 22 orphaned `signal/pages` files (run-loop + `projects/` + `account/`, incl. billing/plans) plus the dead `signal/components/Shell.tsx`, once the Signal-removal waves had ported them IDE-native (`ide/IdeBilling.tsx`, `ide/IdeOrg.tsx`, `ide/IdeSystem.tsx`, `ide/IdeDiscovery.tsx`). Surviving `signal/pages/`: `AuthPages` · `AuthCallbackPage` · `ExtraPages` (forgot/reset/accept-invite/pricing/trust) · `LegalPages` · `MiscPages` (Admin + Shared).
- `LegacyRedirect` collapses old prefixes (`/v3/*`, `/v4/*`, `/signal/*`, `/p/*`, `/dashboard`, `/org/*`, `/exec`, `/team`, …) to canonical paths.

All surfaces share `useAuthStore`, `useUiStore` (theme), `useRunStore`, `useProjectStore`. The legacy V2 sidebar (`AppLayout`) + V3 top-bar (`Shell`) chromes were deleted in `5f5e4aaa`.

`SecurityConfig` whitelists `/api/shared/**` + `/api/invites/preview` for public read paths (V175 cross-org sharing + share-link surfaces).

## SSE event handling

`useSse(runId, token)` hook subscribes to `/api/runs/{id}/events?token=<jwt>` (scoped JWT, 5-min TTL, `scope=sse` claim). Event types it dispatches into the store:

- `PLAN_READY` — opens plan-approval modal.
- `RUN_STATUS` — updates status badge.
- `TASK_STATUS` — updates per-task progress.
- `LIVE_LOG` — appends tool call + LLM completion to the live-log pane.
- `RUN_COST` — updates `CostProgressBar` + cost chip.
- `EXEC_COMPENSATION_UPDATE` / `EXEC_COMPENSATION_DONE` — cancel rollback live cleanup view.
- `RUN_PROVIDER_SWITCHED` — toast on provider fallback.
- `COMPLETE` — terminal `{status, statusReason}` payload; flips badge + tooltip.
