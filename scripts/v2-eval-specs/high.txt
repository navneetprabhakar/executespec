Build a Spring Boot 3.3 REST API for a small library management system.

Entities (JPA, H2 in-memory DB):
- Book: id, isbn, title, author, totalCopies, availableCopies
- Member: id, name, email (unique), joinedAt
- Loan: id, bookId, memberId, loanedAt, returnedAt (nullable)

Endpoints:
- Books: POST /api/books, GET /api/books, GET /api/books/{id}, PATCH /api/books/{id}, DELETE /api/books/{id}
- Members: POST /api/members, GET /api/members, GET /api/members/{id}
- Loans:
  - POST /api/loans/checkout — body {bookId, memberId}; creates a Loan, decrements availableCopies; 409 if none available
  - POST /api/loans/{id}/return — marks returnedAt=now, increments availableCopies; 409 if already returned
  - GET /api/loans?memberId= — lists a member's loan history

Constraints:
- Java 21, Spring Boot 3.3, Spring Data JPA, H2 runtime dep
- Use JDBC via Spring Data JPA (no raw JDBC templates)
- Constructor injection only — no @Autowired on fields
- Bean Validation (@Valid + @NotBlank / @Email) on request DTOs
- A GlobalExceptionHandler returning problem+json (status, error, message)
- Flyway migration V1__schema.sql for the three tables
- Include a README covering run instructions (mvn spring-boot:run) and example curl commands
