Build a cross-platform mobile app using React Native + Expo (managed workflow, TypeScript). The app is a simple habit tracker: one screen that displays a list of daily habits (title + current streak), a "+" button to add a new habit, and a tap-to-increment gesture on each habit card that bumps the streak. Persist habits to the device via AsyncStorage so they survive app restarts. Use @react-navigation/native with a native-stack — the list is the only screen for v1, but wire navigation for future growth. Include jest + @testing-library/react-native unit tests for the habit-card component (renders title + streak; firing onPress increments streak by 1). Pin to the current stable Expo SDK. The smoke command should be `npx expo export --platform android --output-dir dist && npx tsc --noEmit`. Do not emit native `android/` or `ios/` directories — managed workflow only. No README changes beyond install/run instructions if one exists.
