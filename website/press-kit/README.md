## Longer description (suitable for press)

> ExecuteSpec is a spec-driven AI coding platform built for engineering leaders, PMs, and solo developers who want trustworthy code shipping — not just code suggestions. Every run flows through a planner → sequential worker → reviewer pipeline and ends with a 0-100 verified score derived from deterministic signals (build pass, test pass rate, reviewer verdict) rather than LLM self-rating. The platform supports multi-repo project workspaces with architecture docs, tech-debt panels, and RAG-powered project chat. Pricing starts at free (5 runs/month) with a $20/mo Pro tier (20 credits, where $1 = 1 credit) and a $29/mo Max tier with bring-your-own Anthropic/OpenAI/Gemini keys for unlimited use. Built for US + global engineering teams.

## Founding story (1 paragraph)

> I spent 18 months using every "AI coding" tool I could get my hands on — Cursor, Windsurf, Claude Code, Bolt.new, Lovable, v0, Replit Agent. They all have the same shape: generate a diff, hand it to me, shrug. My team ended up doing the same review work we'd always done, just on slightly weirder code. ExecuteSpec started as a bet that the delivery layer — plan → execute → verify — is where the real value lives, not the code-writing layer. The verified score is what makes this concrete: a number that maps to real CI signals, not a vibe-check from the same model that wrote the code.
