# Documentation map

The public source repository keeps documentation needed to understand, build, test, and contribute:

- [README.md](README.md): capabilities, local setup, checks, and layout.
- [AGENTS.md](AGENTS.md): implementation and coding-agent rules.
- [CONTRIBUTING.md](CONTRIBUTING.md): contribution and verification workflow.
- [SECURITY.md](SECURITY.md): private vulnerability reporting and publication hygiene.
- [frontend/CLAUDE.md](frontend/CLAUDE.md): frontend implementation context.
- Package-local `CLAUDE.md` files: backend boundaries and implementation notes.
- [docs/operations/](docs/operations/): maintained code-local operator notes.
- [scripts/build-qualification/](scripts/build-qualification/): executable release qualification.
- [infra/](infra/): optional infrastructure examples and executable runbooks.

Internal business material, personal/operator context, historical captures, and deployment evidence
are maintained separately. The private `executespec-docs` repository is not a prerequisite for
building this repository. Historical references to it do not imply public access.

Generated screenshots, PDFs, presentations, local auth responses, and evaluation results are not
source documentation. Reproduce them locally with the relevant tool and keep them out of Git.
